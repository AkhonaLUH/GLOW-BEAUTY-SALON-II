# GLOW BEAUTY SALON

## About the Website

Glow Beauty Salon is a beauty salon website designed to provide
information about beauty services offered by the salon.

The website includes the following pages:

- Home
- About Us
- Services
- Gallery
- Contact Us

## Part 2 – CSS Styling and Responsive Design

For Part 2, the website was improved by using CSS to create a
consistent and attractive design.

### CSS Improvements

The following changes were made:

- Created an external CSS stylesheet called `style.css`.
- Linked the CSS stylesheet to the HTML pages.
- Added a consistent colour scheme.
- Added font styles and text formatting.
- Added spacing, margins and padding.
- Used Flexbox for the website layout.
- Added borders and box shadows.
- Added hover effects to navigation links and buttons.
- Added responsive styling for different screen sizes.
- Used relative units such as `%`, `em` and `rem`.
- Added responsive images.

### Responsive Design

The website was designed to work on:

- Desktop computers
- Tablets
- Mobile phones

Media queries were used to adjust the layout, font sizes and
navigation for smaller screens.
